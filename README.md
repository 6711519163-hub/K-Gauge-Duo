# K-Gauge-Duo
เกจวัดดิจิทัลไร้สายสำหรับรถจักรยานยนต์ รองรับกล่อง ECU ทั้ง Honda และ Yamaha ผ่านพอร์ต K-Line ส่งข้อมูลความเร็วสูงด้วย ESP-NOW สู่จอสัมผัส 4.3 นิ้ว แสดงผลค่าเครื่องยนต์แบบเรียลไทม์ 0ms อ่านและลบโค้ด DTC พร้อมระบบ Auto-Tune วิเคราะห์ตาราง AFR 5×5 ไฟ Shift Light และเสียงเตือนรอบเกินครบในตัวเดียว
# 🏍️ Dual ECU K-Line Telemetry & Smart Digital Gauge

ระบบมาตรวัดดิจิทัลและตัวอ่านค่ากล่อง ECU รถจักรยานยนต์แบบไร้สาย (Dual-ECU K-Line Reader & ESP32-S3 LVGL Display) รองรับทั้งกล่อง **Honda (Keihin K-Line)** และ **Yamaha (K-Line)** สื่อสารความเร็วสูงผ่านโปรโตคอล **ESP-NOW (60 Hz)**

---

## 🏗️ สถาปัตยกรรมระบบ (System Architecture)

ระบบแบ่งการทำงานออกเป็น 2 หน่วยประมวลผลหลัก สื่อสารกันแบบไร้สายความหน่วงต่ำ (Zero-Latency) บน Wi-Fi Channel 1:

1. **ฝั่งตัวอ่านสัญญาณ (`ecu_reader_c3__1.ino` - Sender Node):**
   - เชื่อมต่อกับสาย K-Line ของรถผ่านวงจรแปลงระดับแรงดัน (Level Shifter 12V ↔ 3.3V)
   - อ่านสัญญาณเซนเซอร์ภายนอกโดยตรง: ตำแหน่งเกียร์ (N, 1–4) และความเร็วล้อ (Wheel Speed Sensor Interrupt)
   - ถอดรหัสข้อมูลดิบและส่งแพ็กเกจออกไปที่ความถี่ ~60 Hz (ทุก 16 ms) และส่งทันทีเมื่อค่าเปลี่ยน
2. **ฝั่งหน้าจอแสดงผล (`display_receiver_s3.ino` - Display Node):**
   - จอสัมผัสขนาด 4.3 นิ้ว (480×272) ตัวควบคุม GT911 ขับเคลื่อนด้วย **LVGL 8.3**
   - มีระบบ **Auto-Tune Fuel Map** เรียนรู้ค่าส่วนผสมน้ำมัน/อากาศ (AFR) แบบ Real-time 5×5 ตาราง
   - ควบคุมไฟ **WS2812B Shift Lights** (ข้างละ 8 ดวง), เสียง Buzzer เตือนรอบเกิน และบันทึกค่า ODO / Trip ลงหน่วยความจำถาวร (NVS)

## 📡 รายละเอียดไบนารีโปรโตคอล (Binary Protocol Specification)

### 1. โปรโตคอลฝั่ง HONDA (Keihin K-Line)

* **พารามิเตอร์ UART:** `10400 bps`, 8 Data bits, No Parity, 1 Stop bit (`8N1`)
* **ลักษณะสายสัญญาณ:** Half-Duplex (ทุกไบต์ที่ส่งออกไปจะสะท้อนกลับมาที่ขา RX เรียกว่า *Hardware Echo* โค้ดจะตัด Echo ทิ้งก่อนประมวลผล)

#### A. ขั้นตอนการปลุกกล่อง (Wake-up & Initialization Sequence)
1. **Bus Init Pulse:** ดึงขา `TX` เป็น `LOW` นาน **70 ms** → ดึงกลับเป็น `HIGH` นาน **130 ms**
2. **Wake-up Frame:** ส่ง `FE 04 72 8C` (กล่องจะตอบกลับ `0E 04 72 7C`)
3. **Initialize Frame:** ส่ง `72 05 00 F0 99` (กล่องจะตอบกลับ `02 04 00 FA`)

#### B. โครงสร้างคำสั่งและการคำนวณ Checksum
* **รูปแบบคำสั่ง (Request):** `[72] [Length] [Service] [Table/Sub] [Checksum]`
* **สูตร Checksum:**
  $$\text{Checksum} = (0x100 - (\sum \text{Bytes} \ \& \ 0xFF)) \ \& \ 0xFF$$

| หน้าที่คำสั่ง | ชุดคำสั่ง Hex (TX) | คำอธิบาย |
| :--- | :--- | :--- |
| **อ่านรหัสกล่อง (ECM ID)** | `72 05 71 00 18` | อ่านหมายเลขประจำตัวกล่อง ECU |
| **อ่านข้อมูลหลัก (Table 17)** | `72 05 71 17 01` | อ่านรอบ, คันเร่ง, อุณหภูมิ, แบต, หัวฉีด, ไฟจุดระเบิด |
| **อ่านข้อมูลเสริม (Table 20)** | `72 05 71 20 F8` | อ่านค่า O2 Sensor (ใช้คำนวณ AFR) |
| **อ่านรหัสปัญหา (Read DTC)** | `72 05 74 01 14` | อ่านโค้ดความผิดปกติที่ค้างในกล่อง |
| **ลบรหัสปัญหา (Clear DTC)** | `72 05 60 03 26` | ลบโค้ดความผิดปกติ (ต้องดับเครื่องยนต์ก่อน) |

#### C. การถอดรหัสไบต์ข้อมูลตอบกลับ (Honda Table 17 & Table 20)
เมื่อตัด Hardware Echo ออกแล้ว เฟรมข้อมูลจากกล่องจะมีโครงสร้าง `[02] [Len] [71] [Table] [Data...]`

* **Table `0x17` (Main Live Data):**
  * **Byte `0x04–0x05` (RPM):** `(Byte[4] << 8) | Byte[5]` *(หน่วย: RPM)*
  * **Byte `0x06` (TPS Volt):** `Byte[6] * (5.0 / 256.0)` *(หน่วย: V)*
  * **Byte `0x07` (TPS %):** `Byte[7] * 0.5` *(หน่วย: %)*
  * **Byte `0x09` (Coolant Temp):** `Byte[9] - 40` *(หน่วย: °C)*
  * **Byte `0x0E` (Battery Volt):** `Byte[14] / 10.0` *(หน่วย: V)*
  * **Byte `0x0F–0x10` (Injector Pulse):** `((Byte[15] << 8) | Byte[16]) / 250.0` *(หน่วย: ms)*
  * **Byte `0x11` (Ignition Advance):** `(Byte[17] / 2.0) - 64.0` *(หน่วย: องศา BTDC)*

* **Table `0x20` (Aux / O2 Sensor):**
  * **Byte `0x04` (O2 Voltage):** `Byte[4] * (2.5 / 128.0)` *(หน่วย: V)*
  * **การแปลงเป็น AFR (ฝั่งจอ):** นำค่า `o2Volt` (0.0V–1.0V) มาแปลงเชิงเส้นเป็น AFR ช่วง `18.0 : 1` (บาง) ถึง `11.5 : 1` (หนา)

* **DTC Frame (`0x74 0x01`):**
  * อ่านทีละคู่ตั้งแต่ Byte `0x03` ถึง `0x07`: `Main Code = Byte[pos]`, `Sub Code = Byte[pos + 1]` (ข้ามค่า `0x00` และ `0xFF`)

### 2. โปรโตคอลฝั่ง YAMAHA (K-Line Stream)

* **พารามิเตอร์ UART:** `15625 bps` (ความเร็วเฉพาะของกล่อง Yamaha; ระบบมี Fallback สแกน `10400 bps` สำรองให้อัตโนมัติ), `8N1`

#### A. ขั้นตอนการปลุกกล่อง (Wake-up Sequence)
1. คงสถานะสาย `HIGH` นาน **320 ms** (Idle High)
2. ดึงสายเป็น `LOW` นาน **25 ms** → ดึงกลับเป็น `HIGH` นาน **25 ms**
3. ส่งไบต์ปลุก `0xFE` หรือส่งคำสั่งดึงข้อมูล `0x01`

#### B. โครงสร้างเฟรมข้อมูลตอบกลับ (5-Byte Stream Frame)
เมื่อส่งคำสั่ง `0x01` กล่อง Yamaha จะส่งข้อมูลกลับมาเป็นชุดความยาวคงที่ **5 ไบต์**: `[B0] [B1] [B2] [B3] [B4]`

| ตำแหน่งไบต์ | ชื่อข้อมูล | สูตรคำนวณ / ความหมาย |
| :---: | :--- | :--- |
| **`Byte 0`** | **Engine RPM** | `Byte[0] * 50` *(ความละเอียดขั้นละ 50 RPM)* |
| **`Byte 1`** | **Vehicle Speed** | ค่าความเร็วจากกล่อง ECU *(โหมดปัจจุบันใช้ Wheel Sensor ภายนอกเป็นหลัก)* |
| **`Byte 2`** | **Fault / Error Code** | ถ้าบิตสูงสุดเป็น 1 (`(Byte[2] & 0x80) != 0`) แสดงว่ามี DTC โดยรหัสคือ `Byte[2] & 0x7F` |
| **`Byte 3`** | **Coolant Temp** | `Byte[3] - 30` *(หน่วย: °C)* |
| **`Byte 4`** | **Checksum** | `(Byte[0] + Byte[1] + Byte[2] + Byte[3]) & 0xFF` *(ผลรวม 4 ไบต์แรกตัดเหลือ 8 บิต)* |

---

### 3. โปรโตคอลไร้สายระหว่างบอร์ด (ESP-NOW Packet Structure)

กำหนดในไฟล์ `shared_data_struct.h` (ใช้ `__attribute__((packed))` เพื่อป้องกันการเลื่อนไบต์ระหว่างสถาปัตยกรรม ESP32-C3 และ ESP32-S3):

| Packet Type | Hex ID | ทิศทาง | ขนาด | รายละเอียด |
| :--- | :---: | :---: | :---: | :--- |
| `PKT_TYPE_GAUGE_DATA` | `0x01` | Sender → Display | 44 Bytes | ค่ามาตรวัดทั้งหมด, สถานะการเชื่อมต่อ, โหลด/อุณหภูมิ CPU ตัวส่ง |
| `PKT_TYPE_HEARTBEAT` | `0x02` | Display → Sender | 5 Bytes | สัญญาณชีพแจ้งตัวอ่านว่าหน้าจอยังเชื่อมต่ออยู่ (ส่งทุก 500 ms) |
| `PKT_TYPE_DTC_DATA` | `0x03` | Sender → Display | 27 Bytes | รายการรหัสเสียสูงสุด 12 รายการ (`mainCode`, `subCode`) และสถานะ `busy` |
| `PKT_TYPE_DTC_CMD` | `0x04` | Display → Sender | 2 Bytes | คำสั่งจากหน้าจอ: `0x01` = อ่านโค้ด, `0x02` = ลบโค้ด |
| `PKT_TYPE_ECM_ID` | `0x05` | Sender → Display | 22 Bytes | รหัสประจำกล่อง ECU ในรูปแบบข้อความ Hex |
| `PKT_TYPE_ECU_SELECT` | `0x06` | Display → Sender | 4 Bytes | เลือกค่ายรถ (`1`=Honda, `2`=Yamaha) พร้อมไบต์ตรวจสอบ `brand ^ 0xA5` และ Magic `0x5A` |

## 🖥️ ฟีเจอร์หน้าจอและการใช้งาน (UI & Features)

* **หน้าหลัก (HOME):** แถบวัดรอบตอบสนองทันที (0ms Lag), ตัวเลขบอกเกียร์พร้อมแอนิเมชันกะพริบเมื่อเปลี่ยนเกียร์, ความเร็ว, รอบสูงสุด (Peak RPM - กดค้างเพื่อรีเซ็ต), ระยะทาง ODO / Trip A / Trip B และ 6 ช่องค่าสำคัญ (AFR, แบตเตอรี่, น้ำหล่อเย็น, เปอร์เซ็นต์ยกหัวฉีด, องศาไฟจุดระเบิด, O2 Volt)
* **ข้อมูลสด (LIVE DATA):** แสดงค่าพารามิเตอร์จาก ECU ครบทั้ง 14 รายการ พร้อมสถานะ CPU ตัวส่งและรหัส ECM ID
* **กราฟ (GRAPH):** พล็อตกราฟ Real-time ย้อนหลัง 120 จุด เลือกเปิด/ปิดเส้นสัญญาณได้อิสระสูงสุด 8 สัญญาณ
* **รหัสข้อผิดพลาด (FAULT CODES):** แปลความหมายรหัสเสียของทั้ง Honda และ Yamaha เป็นภาษาไทย/อังกฤษ พร้อมปุ่มสั่งลบโค้ด
* **ตารางเชื้อเพลิง (FUEL MAP):** ระบบจูนอัตโนมัติ (Auto-Tune) เก็บค่าเฉลี่ย AFR แยกตามตาราง `RPM × TPS` และ `Speed × Gear` พร้อมคำนวณอัตราสิ้นเปลือง (กม./ลิตร)
* **โหมดผู้ดูแลระบบ (ADMIN MODE):** เปิดเมนูหลักแล้ว **กดปุ่มหน้าหลัก (HOME) ค้างไว้ 6 วินาที** (รหัสเริ่มต้น `202030`) สำหรับตั้งค่า ODO, ปรับเทียบเปอร์เซ็นต์ความเร็วล้อ, ตั้งรอบเตือนรายเกียร์, ปรับสีไฟ WS2812B และขนาดหัวฉีด (cc/min)
